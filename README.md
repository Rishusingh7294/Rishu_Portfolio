# Rishu Kumar - Portfolio Website

This is a personal portfolio website built using HTML, CSS, Bootstrap, and JavaScript. It highlights my education, skills, certifications, and machine learning projects.

##  Features

- Responsive design (Mobile and Desktop friendly)
- Bootstrap 5 UI components
- Animated elements using AOS
- Theme toggle (Light/Dark mode)
- Downloadable CV
- Contact form integration (Formspree)
- Interactive project showcase
- Social media links and coding profiles

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- AOS (Animate on Scroll)
- Font Awesome
